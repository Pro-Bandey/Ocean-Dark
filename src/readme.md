## ✨ Features

- 🌊 **Abyssal Navy Palette** – Deep midnight blue tones designed to minimize eye strain during long night coding sessions.
- ⚡ **Bioluminescent Highlights** – Crisp electric cyan accents for active tabs, cursor focus, icons, and interactive elements.
- 📐 **Clean Visual Hierarchy** – High-contrast distinctions between the file explorer sidebar, active editor buffer, and popup modals.
- 🪶 **Native Integration** – Built directly on the native Acode `ThemeBuilder` API for instant rendering and lightweight performance.

## 📦 Installation

1. Open **Acode**.
2. Navigate to **Settings (⚙️) > Plugins**.
3. Search for **Ocean Dark**.
4. Tap **Install**.

---

## 🚀 How to Apply

1. Open **Acode Settings** (⚙️).
2. Tap on **Theme**.
3. Select **Ocean Dark** from the list of installed themes.
4. The new color scheme will apply immediately across the editor and UI panels.
